# Unit Converter

A modern and responsive **Unit Converter** web application built using **HTML, CSS, and JavaScript**. This application provides a clean and intuitive interface for converting values across three essential categories: **Weight**, **Length**, and **Temperature**. Users can easily select the source and destination units, enter a value, swap units with a single click, and receive accurate conversion results instantly.

### Features

* ⚖️ **Weight Converter** – Convert between **Kilograms, Grams, and Pounds**.
* 📏 **Length Converter** – Convert between **Kilometers, Meters, and Feet**.
* 🌡️ **Temperature Converter** – Convert between **Celsius, Fahrenheit, and Kelvin**.
* 🔄 One-click **Swap Units** functionality.
* ⚡ Real-time and accurate conversion calculations.
* 🎨 Modern, responsive, and user-friendly interface with Font Awesome icons and animated UI elements.

This project demonstrates fundamental web development concepts, including DOM manipulation, event handling, JavaScript-based calculations, and responsive UI design, making it an excellent beginner-friendly project for learning front-end development.
